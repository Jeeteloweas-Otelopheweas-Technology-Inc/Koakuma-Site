Koakuma 1.0.10

查询标签专注于 SQL

Query 标签仅显示 SQL 编辑器和查询结果，不再提供「数据 / 结构」切换。从数据表切回 Query 时自动进入 SQL。

移除多余的空白工具栏，数据库工具和结果导出入口并入 SQL 工具栏。

Query tabs stay in SQL

Query tabs now show only the SQL editor and results. Returning from a table’s Data or Structure view automatically opens SQL.

The unused toolbar row is removed. Database tools and result export remain available in the SQL toolbar.
