Koakuma 1.0.9

更完整的 SQL 编辑体验、随图片主题变化的语法颜色，以及更准确的操作图标。

使用 CodeMirror 编辑 SQL

SQL 编辑器现已支持面向 SQLite 的补全与诊断、撤销与重做、搜索以及常用 macOS 快捷键。浅色、深色和图片主题下的选区均可清晰显示。

语法颜色跟随图片主题

SQL、JSON 和代码高亮现在从所选图片的配色中生成，并调整对比度以保证可读性。

完整收录图标并校正语义

内置全部 4,134 个 Game Icons，并重新检查表格、查询、清空、删除、警告等操作的图标，让图形与用途更吻合。

清晰显示全选范围

全选 SQL 时会显示清晰的选区底色，同时保留语法颜色。占位提示也改为更小的字号。

Koakuma 1.0.9

A richer SQL editor, image-inspired syntax colors, and clearer icons.

Edit SQL with CodeMirror

The SQL editor now provides SQLite-aware completion and diagnostics, undo and redo, search, and familiar macOS keyboard shortcuts. Selection remains visible in light, dark, and image themes.

Syntax colors follow your image theme

SQL, JSON, and code highlights now use colors derived from the selected image palette, with contrast adjusted for readability.

A complete icon collection

All 4,134 Game Icons are bundled. Table, query, clear, delete, warning, and other actions have been checked and assigned more appropriate symbols.

Clear selection highlighting

Selecting all SQL text now shows a visible backdrop without hiding the syntax colors. The placeholder also uses a smaller font.
